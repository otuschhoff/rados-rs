# Licensing and Provenance Decision

Original P00 decision: do not choose a distributable project license before
file-level review and human-owner approval. For P12, the human owner approved
`LGPL-2.1-only`; the canonical text is now in the repository root `LICENSE`.
The implementation remains independently written from documented protocol
facts, observations, and small cited source facts. The license selection does
not waive file-level provenance or third-party notice obligations.

The pinned Ceph `COPYING` file states a default of LGPL-2.1 or LGPL-3 and assigns
different licenses to specific subtrees; `doc/*` is CC-BY-SA-3.0. The public C
header carries an LGPL-2.1 notice. This prevents a blanket assumption that all
consulted protocol material has one license.

| Component | Treatment | Distribution |
| --- | --- | --- |
| Generated API inventory | Facts extracted from public declarations; signature text retained for traceability | Review before release because signatures originate in LGPL-covered headers |
| P00 native oracle | Newly written test code linked to librados in isolated infrastructure | Not part of the Go module or production binary; source distribution obligations still apply |
| Go implementation | Independent implementation, with per-file provenance records | Project distribution identity is `LGPL-2.1-only`; provenance review remains required |
| `github.com/otuschhoff/gokrb5/v8` | Apache-2.0 dependency used for RFC 8009 AES256 cryptography | Preserve its license and transitive dependency notices in distributions |
| Binary fixtures | Generated by pinned tools and tagged with source/tool/version | Review redistribution per fixture before commit |
| Ceph containers/tools | Referenced by immutable digest; not redistributed by this repository | Governed by upstream image/package licenses |

Every protocol task must record `independent`, `adapted`, or `ported`, the exact
upstream paths and commit, and applicable notices. Direct translation remains a
stop condition until its specific obligations and notices are reviewed; the
project-level license decision alone is not that review.
